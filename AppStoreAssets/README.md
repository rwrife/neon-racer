# CyberRun App Store assets

- `listing.md` contains the English (US) App Store copy for version 1.0.
- `screenshots/iphone-6.5/` contains landscape 6.5-inch iPhone captures at 2688 × 1242 pixels.
- `screenshots/ipad-13/` contains landscape 13-inch iPad captures at 2752 × 2064 pixels.

Screenshots are unframed PNG captures of the running app on iOS 26.5 simulators using the `testAppStoreScreenshots` UI test. The test runs a Debug build with developer controls hidden; the visuals should be reviewed against the final signed release build before upload. The first screenshot in each set is the title screen; the second shows gameplay.

App Store Connect still needs the account owner's public support and privacy URLs, legal copyright name, age-rating answers, signing, and final review.

Apple's current [screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications) accept both landscape dimensions above.
