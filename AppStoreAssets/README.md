# Neon Racer App Store assets

- `listing.md` contains the English (US) App Store copy for version 1.1.
- `screenshots/iphone-6.5/` contains landscape 6.5-inch iPhone captures at 2688 × 1242 pixels.

The committed 6.5-inch title capture still contains the prior CyberRun wordmark and
must **not** be uploaded as a Neon Racer screenshot. The gameplay capture is also a
Debug simulator draft, not a release asset. Recapture on the final signed iPhone-only
build after the owner approves the title art and logo; no iPad screenshots are shipped.

Screenshots were unframed PNG captures of the running app on an iOS 26.5 simulator using the `testAppStoreScreenshots` UI test. The test runs a Debug build with developer controls hidden; review new captures against the final signed release build before upload.

App Store Connect still needs the account owner's public support and privacy URLs, legal copyright name, age-rating answers, signing, and final review.

Apple's current [screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications) include landscape iPhone captures.
